# Changelog

Each change names the files it touches, so a site can diff just those (README, "Taking over fixes").

## 2026-11-27

- Plain Vite and TypeScript instead of Vite+: `pnpm check` is `cf workers types && tsc --noEmit`, the `format` script, `vite-plus` and the `vite` alias to its core are gone, and `vite.config.ts` imports `defineConfig` from `vite`. Format with `pnpm --package=vite-plus@1.4.0 dlx vp fmt` when needed; `.editorconfig` (new) keeps the tabs that were `fmt: { useTabs: true }`. `package.json`, `pnpm-workspace.yaml`, `vite.config.ts`, `.editorconfig` (new), `README.md`.

- Editing comes from the package `@recranet/worker-site-editor` instead of a copy in each site: sign-in, `/admin/`, texts in D1, images and galleries, and the twelve page parts as its extension blocks. `src/editor.ts` (new) registers the blocks, the text styles and the pages; `src/admin.ts` (new) is the admin bundle's entry (`mountAdmin`). Pages define `texts: { body: { label, default } }` instead of `blocks: { body: { label, text } }`; page keys, text names and stored texts stay the same. Migrations run from the package (`--dir node_modules/@recranet/worker-site-editor/migrations --table editor_migrations`); its first is `CREATE TABLE IF NOT EXISTS block`, so an existing database keeps its texts. `src/components.tsx` keeps only the Footer. `better-auth` and `@portabletext/to-html` are no longer the site's dependencies. `src/editor.ts` (new), `src/admin.ts` (new), `src/blocks.ts`, `src/text-styles.ts`, `src/index.tsx`, `src/components.tsx`, `src/styles/app.css`, `vite.config.ts`, `package.json`, `README.md`; removed `src/admin/`, `src/media.ts`, `src/parts.ts`, `migrations/`.

## 2026-11-26

- Page parts are Portable Text block objects: the customer builds a whole page in the editor. Each page is one `body` text; "Onderdeel" in the toolbar inserts Hero, Tekst naast afbeelding, Kaarten, Kenmerken, Kerncijfers, Oproep, Lopende tekst, Kaart (Google Maps), Uitklapvragen, Citaat met bron, Vinkjeslijst or Labels, and Bewerken opens one Base UI dialog that builds its form from the part's fields in `src/parts.ts` (new): plain texts, links, images uploaded to R2 with alt text, choices and lists of items. Saving checks each part's fields; links must be safe and images `/media/` or `/img/` paths. `text.page("body")` renders each full-width part as its own section and the blocks between them in a text column; `renderPart` in `src/components.tsx` turns a stored part into its component. Home, Over ons, Onderdelen and Contact are one `body` each (the contact form stays below it); their old texts (`intro`, `about`, `feature`, `cta`) are no longer read, so a live site re-enters them or keeps its own block names. `Hero` takes `buttons` instead of `button`, `Buttons` takes `on="dark" | "image"` instead of `onDark`. `src/parts.ts` (new), `src/blocks.ts`, `src/components.tsx`, `src/index.tsx`, `src/admin/admin.tsx`, `src/admin/admin.css`, `README.md`.

- Page parts from the emdash-boilerplate in `src/components.tsx` (new), without JS libraries: Hero (cover or split, one image), Cards (grid or bento), Feature, Features (grid or list), Stats, CTA, Accordion (`<details name>`), Checklist, Quote, Labels, GoogleMap, Marquee and a Footer, which the layout now shows on every page. Home opens with the Hero. A demo page, Onderdelen (`/onderdelen/`), shows each part; a site deletes it. The stylesheet gains the classes they use: `heading-1`–`5`, `stretched-link`, `hero-shade`, `badge`, `article`/`article-sm`, `btn-sm`, `btn-circle`, `btn-white`, `btn-outline-white`, `btn-light`, `btn-overlay`, the success/warning/info colours, `text-display`, the `flow` and `section-half` spacing, `shadow-lg` and the marquee animation. `src/components.tsx` (new), `src/layout.tsx`, `src/index.tsx`, `src/blocks.ts`, `src/styles/app.css`, `public/img/placeholder.svg` (new), `README.md`.

## 2026-11-25

- The admin's text switcher scrolls inside the window when a site has many texts, instead of running off the screen. `src/admin/admin.css`.
- A site's own text styles live in `src/text-styles.ts` (new): paragraph styles, decorators and link styles, each with its toolbar label and the element and classes it renders as. The editor's schema, render and toolbar and the public rendering read from it; saving rejects unknown styles and marks, and a removed style shows as normal text. Examples: a lead paragraph, a highlight and a button link, in home's `about` text, which can now be Portable Text. The admin loads `/style.css` before `admin.css`, so the editor shows the styles as the page does. `src/text-styles.ts` (new), `src/blocks.ts`, `src/admin/admin.tsx`, `src/admin/admin.css`, `src/admin/index.tsx`, `src/styles/app.css`, `README.md`.
- More languages, optional: `languages` in `src/languages.ts` (new) lists the site's languages, `nl` alone by default, which keeps every path as it was. With more, pages live under `/<lang>/`, `/` redirects to the first language, each page in `blocks.ts` has a `lang` and `translates`, and routes use `href(page)`. `<html lang>`, the navbar (that language's pages and a language switch), `hreflang` links, the form texts and errors, the thank-you page and the 404 follow the page's language. `Layout` takes `url={c.req.url}` instead of `path`, and the form posts a hidden `lang`. The admin lists pages by language. `src/languages.ts` (new), `src/blocks.ts`, `src/index.tsx`, `src/layout.tsx`, `src/contact.ts`, `src/admin/index.tsx`, `README.md`.

- Galleries are editable: Bewerken under a gallery opens a Base UI Dialog to change alt texts, reorder, remove and add images; Toepassen updates the block in place (`block.set`). `src/admin/admin.tsx`, `src/admin/admin.css`.
- Galleries and scaled images: a "Galerij" button inserts a `gallery` block (`images`: src, alt, width, height each), shown as a square grid that opens in a lightbox (`public/gallery.js`, the dialog in `src/layout.tsx`). With `IMAGES` (Cloudflare Images) `/media/<id>?w=<width>` serves WebP at 480, 960, 1440, 1920 or 2560 px, cached at the edge, and images get a srcset. Uploads up to 20 MB. `src/media.ts`, `src/blocks.ts`, `src/index.tsx`, `src/layout.tsx`, `src/admin/admin.tsx`, `src/admin/admin.css`, `public/gallery.js` (new), `cloudflare.config.ts`, `README.md`.
- Images in the texts: an "Afbeelding" button uploads to R2 (`MEDIA`) and inserts a Portable Text `image` block (`src`, `alt`, `width`, `height`); public pages render it as `<img>`, served from `/media/<id>`. `src/media.ts` (new), `src/admin/index.tsx`, `src/admin/admin.tsx`, `src/admin/admin.css`, `src/blocks.ts`, `src/index.tsx`, `cloudflare.config.ts`, `README.md`.
